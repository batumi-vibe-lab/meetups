# 2026-11-01 — ИИ вместо подрядчика, свой софт под себя

**Где:** Parnavaz Mepe, 18

## Ключевые выводы

Номера в скобках — блоки в полных тезисах.

- **С ИИ один человек или команда без программистов закрывают задачи, под которые раньше искали подрядчика.** Сделка от оценки рынка до контрактов, программа для обменников вместо заказной разработки, дизайн-проект квартиры за сутки вместо дизайнера (1, 2, 9.8).
- **Свой софт под себя — рабочий путь.** По мнению участников, универсальные решения не учитывают тонкостей бизнеса, а написать своё теперь быстрее и дешевле. Предприниматель без навыков программирования за год сделал больше десяти сервисов и инструментов для себя, один из них дорабатывает до продукта для других (9, 13).
- **Сделать для себя и довести до продукта — разные задачи.** Продукт планировали закончить к июню, а его до сих пор «чистят от шелухи». Схему с моделями через подписку и браузер, по мнению трейдера, в коммерческий продукт не вывести (9.5, 11.2).
- **Разработка подешевела, конкуренция смещается в продуктовое мышление, постановку задачи ИИ и маркетинг.** Прототип заказчик видит сразу, путь от идеи до прода — до следующего дня (3.7, 8.1).
- **Повторяющийся запрос к клубу — как выстроить работу с агентами.** Субагенты, контекст, изоляция, безопасный деплой, автономность (1.2, 2.2, 7). Предприниматель готов показать свою схему (25).
- **Железо под локальные модели — дорогой эксперимент.** По опыту участников, без понятной задачи и софта Mac Studio или стойка простаивают (12).
- **Местный рынок — возможный источник заказов.** По словам девелопера, госорганы Аджарии готовы платить за решения для города, но не на Telegram и не на Яндексе (19, 20).
- Квартиры загородного клубного дома предложили продавать как закрытый клуб — через интервью и рекомендации, в обход риелторов (24).
