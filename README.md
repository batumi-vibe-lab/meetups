## ✍️ Как добавить встречу

1. Создай папку в формате `ГГГГ-ММ-ДД-тема`, например `2026-11-15-kickoff`.
2. Положи туда `README.md` по шаблону ниже, а рядом — слайды, тезисы и другие файлы.
3. Нет Write-доступа? Создай issue с материалами — кто-нибудь из контрибьюторов перенесёт.

Пример структуры:

```
2026-11-15-kickoff/
├── README.md
├── slides.pdf
└── prompts/
    └── demo-prompt.md
```

Шаблон `README.md` встречи:

```markdown
# ГГГГ-ММ-ДД — Тема встречи

**Где:** Parnavaz Mepe, 18
**Ведущие / спикеры:** ...

## О чём говорили
- ...

## Ключевые выводы
- ...

## Что решили и кто что делает
- [ ] задача — @исполнитель

## Ссылки и материалы
- ...
```

> 🔒 Репозиторий приватный. Не выкладывай чужие слайды, промпты и цифры наружу без согласия авторов и не коммить ключи и токены.
