## ✍️ Как добавить встречу

1. Создай папку в формате `ГГГГ-ММ-ДД-тема`, например `2026-11-15-kickoff`.
2. Положи туда `README.md` по шаблону ниже, а рядом — тезисы, отчёты и другие файлы.
3. Слайды положи в `presentations/archive/` в папку с тем же названием, что у встречи, и поставь на них ссылку из README встречи. Подробнее — в [presentations/README.md](presentations/README.md).
4. Нет Write-доступа? Создай issue с материалами — кто-нибудь из контрибьюторов перенесёт.

Пример структуры:

```
2026-11-15-kickoff/
├── README.md
├── theses.md
└── prompts/
    └── demo-prompt.md

presentations/archive/2026-11-15-kickoff/
└── slides.pdf
```

Шаблон `README.md` встречи:

```markdown
# ГГГГ-ММ-ДД — Тема встречи

**Где:** Parnavaz Mepe, 18
**Ведущие / спикеры:** ...

## О чём говорили
- ...

## Ключевые выводы
- ...

## Что решили и кто что делает
- [ ] задача — @исполнитель

## Ссылки и материалы
- ...
```

> 🔒 Репозиторий приватный. Не выкладывай чужие слайды, промпты и цифры наружу без согласия авторов и не коммить ключи и токены.
