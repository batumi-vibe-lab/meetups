# 🎞 Презентации

Слайды и демо-материалы спикеров. Итоги и тезисы встречи остаются в её папке, а презентации лежат здесь.

```
presentations/
├── archive/   — показанные на прошедших встречах
└── drafts/    — готовятся к будущим встречам
```

## 🗂 archive — прошедшие встречи

Одна папка — одна встреча. Название совпадает с папкой встречи: `ГГГГ-ММ-ДД-тема`. Внутри — файлы спикеров, в названии файла — тема или автор.

```
archive/
└── 2026-11-15-kickoff/
    ├── agents-workflow.pdf
    └── demo-prompts.md
```

Из README встречи поставь ссылку на презентацию в разделе «Ссылки и материалы».

## ✏️ drafts — готовятся

Папка на каждую будущую презентацию. Если дата встречи известна — `ГГГГ-ММ-ДД-тема`, если нет — просто `тема`. Черновики можно править сколько угодно, никто не ждёт от них готовности.

После встречи перенесем папку в `archive/`, при необходимости переименуй под дату встречи и добавь ссылку в README встречи.

> 🔒 Не выкладывай чужие слайды наружу без согласия авторов. Перед переносом в архив проверь, что в файлах нет ключей, токенов и личных данных, которые автор не хотел показывать.
